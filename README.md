# structured-content
Contenido estructurado con IA, Markdown y HTML semántico

Este repositorio funciona como una plantilla para organizar información y transformarla en una página web utilizando Markdown, HTML, CSS e IA como herramienta de apoyo.

html.md

Guía de consulta sobre HTML.

Explica la estructura básica de un documento, etiquetas, atributos, semántica, jerarquía, enlaces, imágenes y la relación entre elementos.

prompt.md

Instrucciones base para trabajar con IA.

# Prompt base · Markdown → HTML

Utiliza base.html como plantilla y content.md como fuente de información.

Convierte el contenido de content.md en un documento HTML semántico, manteniendo la estructura general definida en base.html.
