HTML, estructura y cajas

Los elementos HTML generan cajas, pero cada elemento tiene una función dentro del documento.

Elementos Estructura Jerarquía

Los elementos HTML son cajas

Cada elemento ocupa un espacio dentro del documento. El navegador calcula su tamaño, posición y relación con otros elementos.

No todas las cajas son iguales

Un título, un párrafo y un enlace generan cajas, pero tienen funciones diferentes.

Esto es un enlace

Las cajas forman estructuras

Una caja puede contener otras cajas. Las etiquetas HTML describen cómo se relaciona cada parte del contenido.

Una estructura contiene más estructuras

Este artículo está dentro de una sección y contiene a su vez un título y un párrafo.

Las etiquetas crean jerarquía

Un h1 representa el título principal. Un h2 identifica una sección. Un h3 introduce un nivel secundario.
